Kenglish -- Quản lý bộ từ vựng
Tổng quan
Kenglish là ứng dụng học tiếng Anh trên Android, hỗ trợ người dùng
tổ chức và quản lý từ vựng theo thư mục (Folder) và bộ từ.
Công nghệ sử dụng
- Java + XML --- phát triển giao diện và xử lý logic ứng dụng
  Android.
- Node.js + Express.js --- xây dựng Backend REST API.
- MySQL --- lưu trữ người dùng, thư mục, bộ từ và từ vựng.
- Retrofit --- kết nối ứng dụng Android với Backend REST API.
- JWT (JSON Web Token) --- xác thực người dùng và bảo vệ API.
- RecyclerView + Adapter --- hiển thị và quản lý danh sách thư
  mục, bộ từ.
- Git + GitHub --- quản lý mã nguồn và phiên bản.
Công nghệ / tính năng nổi bật
Dictionary Lookup / Auto-fill
Tích hợp chức năng tra từ tự động. Khi người dùng nhập từ tiếng Anh,
hệ thống tra cứu dữ liệu và tự động hỗ trợ điền các thông tin như:
- Nghĩa tiếng Việt
- Phiên âm
- Loại từ
- Các thông tin từ vựng liên quan
Drag & Drop Vocabulary Management
Hỗ trợ kéo và thả bộ từ vào thư mục, đồng thời cập nhật thay đổi
xuống cơ sở dữ liệu thông qua REST API.
RESTful API + JWT Authentication
Android giao tiếp với Backend thông qua REST API, dữ liệu trao đổi
bằng JSON và các API cần đăng nhập được bảo vệ bằng JWT Bearer
Token.
Chức năng quản lý từ vựng
- Tạo thư mục.
- Tạo bộ từ.
- Di chuyển bộ từ vào thư mục.
- Xem danh sách bộ từ trong thư mục.
- Tìm kiếm bộ từ theo tên.
- Thêm và xóa từ vựng.
- Đánh dấu từ Đã thuộc / Chưa thuộc.
- Tra từ và tự động điền thông tin từ vựng.
